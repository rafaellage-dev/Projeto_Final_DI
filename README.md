# README Projeto_Final
Antes de iniciar a contrução do site em si, inicialmente pensei no tema do meu projeto, qual seria meu público-alvo, e quais elementos ele poderia ter. Depois, construí um protótipo no Canva, um esboço, de como eu visualizava meu site finalizado. Nesse protótipo, fui adicionando elementos e cores de modo a respeitar as WCAG, as Heurísticas de Nielsen, UI/UX e buscando sempre escolher as cores seguindo a psicologia das cores. Fiz tanto uma versão para modo claro quanto uma versão para modo escuro, com variações de cores. Além disso fiz uma logo no Canva (sem IA). Depois gerei imagens e textos fictícios com Inteligência Artificial para compor o site. Posteriormente iniciei o desenvolvimento do código do meu site no VS Code utilizando HTML, CSS e JavaScript. 

Comecei fazendo minha página inicial, a Index.html, onde criei minha barra de navegação, inicialmente incluindo a logo do site e links para acessar as demais páginas, coloquei uma imagem de placeholder no começo da Index, adicionei um título e um span, cards com alguns produtos, descrições e preços, um botão que direcionava o usuário para a página da loja, que ainda não estava feita, e um card explicando o que são as trufas e concluí a Index.html fazendo o rodapé, que era bem parecido com a barra de navegação mas tinha ma organização diferente. Enquanto fazia o HTML do site, eu ia, simultaneamente, buscando tutoriais de como fazer certas funcionalidades e ia desenvolvendo meu código CSS na mesma medida, também buscando tutoriais e aprendendo a mudar coisas específicas no HTML com CSS. 

Depois, fiz o código da Loja.html, incluindo nela um carrossel com 9 cards mostrando todos os produtos vendidos. Para fazer essa funcionalidade, busquei principalmente na W3 Schools lições que ensinassem sobre como fazer o carrossel. O carrossel foi feito utilizando um script em JavaScript. Em seguida fiz a página Sobre.html, onde coloquei uma imagem gerada pelo Gemini, junto com um texto que descreve a história fictícia da loja de trufas. Adicionei também um carrossel simples e automático no início da página inicial. 

Posteriormente, fiz os códigos das páginas Contato.html e Login.html, que consistem em dois formulários não funcionais pois o site não está hospedado em nenhum servidor e, muito menos um arquivo PHP para a recepção e validação das informações. Após terminar de desenvolver a estrutura principal do site, fiz as funcionalidades de modo claro/escuro e de aumentar/diminuir a fonte dos textos. Para tal, criei funções em JavaScript que alternassem o modo como o CSS exibia as cores conforme o clique no ícone de lua que acrescentei à barra de navegação. Fiz o mesmo para a função de alternar o tamanho da fonte mudando, para isso, a escala dos textos e de certos elementos para que se adequassem a essa mudança de tamanho, e utilizando também um script em JavaScript. 

Em seguida, fiz uma barra de pesquisa na barra de navegação utilizando os formulários do HTML. Essa barra de pesquisa, 100% funcional, possui a capacidade de reconhecer o texto inserido por meio de um script em JavaScript e sugerir o produto que o usuário está buscando. Ao clicar em uma sugestão ou digitar o nome de algum produto válido, o cliente é redirecionado à página correspondente ao produto desejado. Essa última função é realizada pelo mesmo script em JS. Caso o usuário digite um nome que não corresponde a nenhum produto, nada acontece se ele tentas pesquisá-lo. 

Por fim, criei uma página para cada produto e fiz com que, ao clicar em qualquer card que mostre algum produto, a pessoa é direcionada para a página daquele produto, e incluí nessas páginas uma opção para voltar para a Loja.html.
